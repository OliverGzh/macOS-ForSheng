# macOS 27.3 迁移要求

用户已于 2026-11-15 确认迁移到 macOS 27.3，优先复用 UniXNU 已验证的 sheng 路线。

1. 当选择新路线时，构建必须统一使用 `macos-27.3-26C5035r` 的内核配置、原版系统组件、驱动 ABI 和启动配置；不得混入旧 25F71 Recovery 产物。
2. 当获取依赖时，必须使用固定提交，保留上游许可证及来源，并拒绝覆盖未知的现有修改。
3. 当构建时，必须接入上游 Adreno/Metal、显示、触控、UFS、网络、USB、音频与电源实现，而不是继续使用旧 Recovery 的 CPU 显示和 QEMU 输入作为真机驱动。
4. 当生成配置和检查报告时，必须区分上游真机证据、本仓库主机检查和本仓库尚未执行的真机验证。
5. 当使用构建工具时，仅允许修改主机构建文件；不连接设备、不执行刷机或分区命令，不发布可刷机 Release。
6. 当查看首页及构建文档时，必须保留“尚未成熟，请勿刷机”的提醒，并保留 26.5 实验记录以供对照。
